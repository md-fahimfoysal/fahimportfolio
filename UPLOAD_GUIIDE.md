📘 UPLOAD TO NETLIFY (EASIEST - RECOMMENDED)
═════════════════════════════════════════════

1. Go to: https://netlify.com
2. Click "Sign Up" → Choose "GitHub"
3. Authorize Netlify with your GitHub account
4. Click "New Site from Git"
5. Select your repository containing the portfolio
6. Build settings:
   - Build command: (leave empty)
   - Publish directory: . (root folder)
7. Click "Deploy Site"
8. Wait 30 seconds ✓ Your site is live!
9. Get your free URL: https://your-site.netlify.app
10. (Optional) Add custom domain in Site Settings

Pros: Free HTTPS, free CDN, automatic updates, very fast
Time: ~5 minutes
Cost: FREE (up to 300 builds/month)

📘 UPLOAD TO VERCEL (FAST & SIMPLE)
────────────────────────────────────

1. Go to: https://vercel.com
2. Click "Sign Up" → Choose "GitHub"
3. Click "New Project"
4. Select your repository
5. Framework: "Other" (static)
6. Root Directory: . (current)
7. Click "Deploy"
8. Wait 1 minute ✓ Live!
9. URL: https://your-project.vercel.app

Pros: Extremely fast, free, automatic SSL, global CDN
Time: ~3 minutes
Cost: FREE

📘 UPLOAD TO GITHUB PAGES (FREE)
────────────────────────────────

1. Create/push files to GitHub repository
2. Go to Settings → Pages
3. Under "Source" select "main" branch
4. Folder: "/ (root)"
5. Click Save
6. Wait 2 minutes ✓ Live!
7. URL: https://username.github.io/repository-name

Pros: Free, integrated with GitHub, automatic
Time: ~5 minutes
Cost: FREE

📘 UPLOAD TO TRADITIONAL HOSTING (Bluehost, GoDaddy, etc.)
──────────────────────────────────────────────────────────

METHOD 1: File Manager (easiest)
1. Login to cPanel
2. Go to File Manager
3. Navigate to public_html folder
4. Upload all files here
5. Done! Visit your domain

METHOD 2: FTP Upload
1. Connect via FTP (FileZilla, WinSCP)
2. Server: ftp.yourdomain.com
3. User: Your cPanel username
4. Password: Your cPanel password
5. Navigate to public_html
6. Drag & drop all files
7. Done!

Pros: Your own domain, custom email
Time: ~10 minutes
Cost: Usually $2-10/month

📘 UPLOAD TO AWS S3 (FOR ADVANCED USERS)
────────────────────────────────────────

1. Go to: https://aws.amazon.com/s3/
2. Create S3 bucket with your domain name
3. Upload all files to bucket
4. Enable static website hosting
5. Create CloudFront distribution (CDN)
6. Point domain via Route 53
7. Enable SSL certificate (ACM)

Pros: Scalable, global CDN, very reliable
Time: ~30 minutes
Cost: $0.50-2/month typically
